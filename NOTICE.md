# Nadev Box notices

Nadev Box is a modified distribution of
[fscarmen/sing-box](https://github.com/fscarmen/sing-box).

The upstream project and its contributors retain credit for the existing
implementation, including the terminal menu framework, protocol installers,
NAT and Hysteria2 functionality, and subscription generation. This fork keeps
the upstream GPL-3.0-or-later licensing terms in [LICENSE](LICENSE).

Nadev-specific changes currently provide the `nb` command (while retaining
`sb` compatibility), a Nadev-branded dashboard, the read-only Nadev Doctor,
installation/update paths that point to `jiajia2222/nadev-box`, and Nadev Box
Docker/configuration entrypoints. The Docker image includes this notice for
offline attribution.

Upstream source: <https://github.com/fscarmen/sing-box>
