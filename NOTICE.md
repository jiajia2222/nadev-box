# Nadev Box notices

Nadev Box is a modified distribution of
[fscarmen/sing-box](https://github.com/fscarmen/sing-box).

The upstream project and its contributors retain credit for the existing
implementation, including the terminal menu, protocol installers, NAT and
Hysteria2 functionality, diagnostics, and subscription generation. This fork
keeps the upstream GPL-3.0-or-later licensing terms in [LICENSE](LICENSE).

Nadev-specific changes currently provide the `nb` command (while retaining
`sb` compatibility), a Nadev-branded menu header, and installation/update
paths that point to `jiajia2222/nadev-box`.

Upstream source: <https://github.com/fscarmen/sing-box>
